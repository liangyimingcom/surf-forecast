### 剩余细节（合理默认，已锁定）
- 定向通知作废 → **公开「更新日志」页** + 匿名**认领码**查自己那条状态。
- 版本：**semver，每条 patch 自增**（vX.Y.**Z+1**）；ECR 镜像打**不可变版本 tag**（`:latest` 仅指针）。
- 自动路径仍走 **PR → 自动合并**（留审计记录），不直接 push master。
- **单一自动写者**：Pipeline 是唯一自动改码者；nightly codelens cron 保持**只读**；EventBridge refresh 与之**时段错开**。
- 回滚镜像**保留最近 N=10 个**版本 tag。

## 二、红线（硬约束，非 AI 判断）

1. **自动化边界四条件同时成立才无人值守上线**：① 改动路径 ∈ 白名单 `{web/浪报MVP.html, web/e2e/ 只读不改}` ② 非"删除功能" ③ pytest + 既有 E2E + dynamo 契约全绿 ④ diff 通过 secret/后门/新增出网端点扫描。**任一不满足 → 人工对话放行路径**。
2. "纯前端"由 **CI 强制的路径白名单**判定，**不靠 AI 自述**；**删除功能永不自动**。
3. **冻结 E2E**：自动路径禁改 `web/e2e/`；需动测试的需求强制人工路径。
4. **无版本镜像禁止上线**；`:latest` 被覆盖 = 无回滚物，故每版必打不可变 tag。
5. **Pipeline 串行**处理 accepted 需求；每次基于最新 master rebase（单 HTML 文件冲突）。
6. **用户输入/页面内容 = 不可信数据**：脱敏 + 反注入（系统指令与数据分隔）+ 长度上限；对 AI 生成 diff 做安全扫描。
7. **可回滚性分级**：纯前端 = 可回滚（切上一镜像）；含 DynamoDB 数据/schema = **不可回滚，只能前向修复**（自动路径本就禁数据变更，故自动路径永远可回滚）。
8. **自动过期用 status 状态机**（`new/triaged/accepted/in_progress/shipped/rejected/expired`）；TTL 仅清 `status∈{new,rejected}` 且超期者；**已采纳/进行中绝不被删**（防"冷点炸弹"同类耦合）。
9. CodeLens/源码/token **绝不暴露给用户**（仅后端调用，token 仅后端）。
10. **Pipeline 有 kill-switch**（STOP 文件）+ 每日自动合并**硬上限** + 运行看板。
11. 沿用既有红线：GMT+8 / DATA CONTRACT 含 wdeg / DynamoDB float→Decimal / `/api/*` 全 401 / ALB SG 禁 0.0.0.0/0（仅 pl-58a04531）/ terraform 禁 `-auto-approve`。
12. 每轮开发用 skill `surf-forecast-codelens-dev` 摸底 + 算爆炸半径 + 守红线；pytest/E2E 零倒退。

                          │ (本地用 oversea1 凭证读云端库)
┌─ 本地 MeshClaw 大脑 ──────▼──────────────────────────────────────┐

## 四、分阶段路线（每阶段独立可上线，逐阶段人工确认后再进）

- **Phase 0 版本/回滚/可观测地基（先做，是一切前提）**
  ECR 不可变版本 tag(vX.Y.Z) ↔ commit ↔ CHANGELOG ↔ 部署时间 审计链；`deploy.sh` 发布自动写
  「YYYY-MM-DD HH:MM GMT+8 · vX.Y.Z · 需求ID · commit · 结果」；新增 `deploy.sh rollback`（切上一版本镜像 + 记录）；
  部署后**真浏览器 E2E 金丝雀**，失败自动 rollback；catalog/cams/report 计数跌 0 告警。
- **Phase 1 反馈落库 + 页面感知澄清 agent（云端）**
  `/api/feedback` 落 DynamoDB 新表(float→Decimal, status 状态机, TTL 按 status)；page-schema 从代码派生；
  澄清 agent(基于 page-schema，调外部 LLM 网关，≤4 轮收敛，可跳过，每IP限流，网关超限降级模板)；
  产出结构化需求对象 `{类型:新增/改进/删除/bug, 页面, 复现, 期望, 验收标准, 可回滚性}`；公开更新日志页 + 认领码。
- **Phase 2 MeshClaw 对话审阅（gate1）**
  MeshClaw 定期拉待审(去重合并 + 垃圾/PII 过滤 + 优先级) → 对话里 accept/reject；accept→status=accepted 进队列；reject/超期 TTL 清。
- **Phase 3 本地 Autonomous Pipeline 出 PR（gate2 红线门，串行）**
  读 accepted → codelens 摸底 → draft PR（路径白名单判定自动/人工；既有 pytest+E2E+dynamo 契约全绿 + diff 安全扫描才提 PR）；
  PR 附「验收标准 vs 实现」自评 + 截图；幂等去重，失败不无限重试。
- **Phase 4 合并 + 受控发布**
  自动路径(白名单+非删除+全绿+扫描过)→自动合并+发布+真浏览器金丝雀；否则对话 ping 人工放行后合并。
  每条 semver+1 打 tag + 写 CHANGELOG；金丝雀失败 rollback；需求 status→shipped，更新公开更新日志。

**DoD（每阶段）**：pytest/E2E/dynamo 契约全绿 + 0 JS 报错；红线零违反；审计链完整；人工确认后进下一阶段；全程 GMT+8。

**范围外（明确不做）**：AI 判定"纯前端"（必须路径白名单）；删除功能走自动；无版本镜像上线；并发改单文件；含数据变更走回滚；向匿名暴露 CodeLens/源码；无 kill-switch/无预算上限的自动化；TTL 误删已采纳需求；改动 E2E 后仍走自动路径。

## 六、开工前需先验证的前提（Phase 0 第一步）
1. **云端 ECS → `<llm-gateway-host>` 连通性**：`*.people.aws.dev` 内网域，生产 ECS(账号 153705321444) 能否出网直连未知——不可达则澄清 agent 调不通，需 NAT/代理或退"云端模板+本地才调网关"。
2. **:latest 覆盖现状**：确认当前部署确实覆盖 `:latest`（则历史无回滚物），Phase 0 必须先引入版本 tag 才能谈回滚。
3. **master 分支保护策略**：确认本地 Pipeline 能否自动合并 PR 到 master（bot 权限/保护规则）。
